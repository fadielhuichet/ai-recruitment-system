# Home Page Redesign Brief (Stitch)

## Goal
Redesign the public Home page to feel premium, modern, and high-converting for recruiters and candidates.

## Brand
- Name: RecruWise
- Tone: trustworthy, modern, AI-powered, clean
- Primary color: #0f766e (teal)
- Secondary: slate/neutral palette

## Audience
- Primary: recruiters and hiring managers
- Secondary: job seekers

## Page Sections (keep same order)
1) Hero
2) Social proof stats
3) Features grid
4) How it works (3 steps)
5) Featured jobs (latest 3)
6) CTA for recruiters
7) Footer

## Requirements
- Must be responsive (mobile-first, tablet, desktop).
- Keep CTAs above the fold.
- Include a "Browse Jobs" CTA and a secondary "I am a Recruiter" CTA.
- Featured jobs are dynamic cards (3 items).
- Keep a premium SaaS look with subtle gradients, soft shadows, and clean typography.

## Copy (use same text)
- Headline: "Stop reading resumes. Start interviewing."
- Subheadline: "Analyze candidates, rank applications instantly, and make faster, data-backed hiring decisions with RecruWise. Stop sorting resumes, start interviewing the best."
- CTA primary: "Browse Jobs"
- CTA secondary: "I am a Recruiter"
- Social proof labels: Jobs Posted, Resumes Analyzed, Active Recruiters, Faster Hiring
- Features titles:
  - AI Candidate Scoring
  - Smart Management
  - Fast Hiring Decisions
  - Centralized Dashboard
- How it works:
  - Post a Job
  - Receive Applications
  - AI Ranks the Best
- Featured jobs title: "Latest Opportunities"
- CTA banner title: "Ready to hire smarter?"
- CTA banner body: "Join hundreds of recruiters who use RecruWise to automate resume screening, organize applicants, and close roles faster."
- CTA banner button: "Create Recruiter Account"

## Functional Elements
- Primary CTA: routes to /jobs
- Secondary CTA: routes to /login (only show when not authenticated)
- Featured jobs cards show: company initials, category, title, company, location, date
- "View Details" button goes to /job-details/:id

## Visual Direction
- Layout: wide hero with text + product mockup or illustration
- Use layered backgrounds and subtle glows
- Use rounded cards, soft borders, and light shadows
- Keep spacing generous and typography bold for headings
- Minimal icons, consistent line/solid style

## Accessibility
- Use sufficient contrast for text on backgrounds
- Buttons must have clear hover/focus states

## Deliverable
- Provide an updated layout and style spec that preserves content but improves visual hierarchy and conversion.
